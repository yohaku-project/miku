ひみつのおへや｜配布ページセット

同梱ファイル
  index.html               配布ページ
  himitsu-no-oheya.html    ゲーム本編（オフラインでも動作）

使い方
1. zipを展開します。
2. index.htmlをブラウザで開くと、配布ページを表示できます。
3. 「ホームページへ入る」からゲームをプレイできます。
4. 「HTMLファイルをダウンロード」からゲーム本編だけを保存できます。

Web公開するとき
index.html と himitsu-no-oheya.html を同じディレクトリに配置してください。
GitHub Pages の場合、リポジトリの公開対象フォルダへ両方アップロードすると、index.html が配布ページになります。
